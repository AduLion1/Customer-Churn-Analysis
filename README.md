Customer Churn Analysis
This project analyzes customer churn patterns using Python, SAS, and Power BI. The goal is to identify key factors associated with customer churn and provide insights that can support customer retention strategies.
Tools Used
- Python – Pandas, Seaborn, Matplotlib, SciPy
- SAS – Statistical analysis
- Power BI – Interactive dashboard and visualization
Key Insights
- Overall churn rate: 47.37%
- Female customers showed a higher churn rate than male customers.
- Monthly contracts had the highest churn rate.
- Payment Delay and Support Calls showed notable positive relationships with churn.
